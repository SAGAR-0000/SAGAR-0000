### 🔧 [Mechanic Mitra](https://github.com/SAGAR-0000/Mechanic-Mitra)
**Enterprise Multi-Agent Diagnostic System**

Kaggle "AI Agents Intensive" course capstone — 4 coordinated agents (Visual, Audio, Pricing, Chief) using Gemini 2.5's multimodal capabilities.

- **Impact:** 45-min manual inspection → 3-min automated assessment
- **Engineering:** Custom orchestration, persistent JSON-based fault memory, exponential backoff for API resilience under rate limits (15 RPM)
- **Stack:** `Gemini 2.5` `Multi-Agent Orchestration` `Python`

### 🩺 [Hypertension Screening System](https://github.com/SAGAR-0000/Hypertension-Classification-from-PPG-Signals)
**Bio-medical ML on PPG Signals**

XGBoost classifier for early hypertension screening, trained on 25,201 PPG signals with subject-independent validation.

- **Impact:** 87.88% accuracy, 93.84% specificity
- **Engineering:** GroupShuffleSplit to prevent data leakage, SMOTE for class imbalance, LF/HF frequency-domain feature optimization
- **Stack:** `XGBoost` `Signal Processing` `SMOTE`
